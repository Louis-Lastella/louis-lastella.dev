# louis-lastella.dev

Mein Portfolio, live unter [louis-lastella.dev](https://louis-lastella.dev).

Alle Inhalte stehen im Datenblock oben in `index.php`. Bei jedem Push auf `main` rendert eine GitHub Action die Datei zu statischem HTML und veröffentlicht sie über GitHub Pages.

Lokal ansehen:

```bash
php -S localhost:8000
```
